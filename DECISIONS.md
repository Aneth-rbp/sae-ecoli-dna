# Decisions

Analysis decisions, mirrored from issue #14. Each entry states what was decided and why.

## Settled

- **Main analysis uses the top-N genes per unit; activation > 0 is secondary.** A zero threshold on the baseline marks each dimension active in about half the genes, which makes the comparison with a sparse SAE unfair.
- **The SAE is trained on genomic windows.** About 3,000 genes are too few rows to train a dictionary; 1 kb windows with a 500 nt step add roughly 9,000 rows per strand.
- **The SAE has 128 features with k = 32 (#31).** Mean-pooled window embeddings are nearly low-rank: 1, 4, 12 and 30 principal components explain 50, 80, 95 and 99 % of the variance. With 1,024 features no k met the rule (k = 16: 83 % dead; k = 32: 66 %), and more epochs raised the dead fraction (88 % and 86 % at 100 epochs). The rule from #14 (explained variance >= 0.8, dead < 20 %) was applied to 64, 128 and 256 features times k = 16 and 32, taking the largest passing dictionary and then its smallest k: 128 features with k = 32 gives explained variance 0.986 and 10 % dead. 256 features failed (31 % dead at k = 32).
- **Evo 2 7B in bf16 on the DGX Spark replaces Nucleotide Transformer v2 50M.** The Spark's GB10 GPU is not Hopper, so the FP8 checkpoints (40B, 20B, 1B) are out and the 7B runs without Transformer Engine; the Windows dev machine only downloads data and runs tests. Known risk: Evo 2 recommends torch 2.6 or 2.7, while the NGC 25.10 image that supports GB10 ships torch 2.9.
- **N for top-N is 50.** About 1.5 % of the roughly 3,000 genes keeps each unit's gene set specific while leaving enough genes for the hypergeometric test against GO terms.
- **A tie that crosses the top-N cut is dropped whole, so a set can hold fewer than N genes.** 42 of the 128 SAE features are active (> 0) in fewer than 50 genes, many in none. Filling their top 50 with zero-activation genes in table order picked the first genes of the genome (*thr*, *cai*, *fix* operons), and 40 features shared a spurious best term (amino-acid betaine / carnitine metabolism, adjusted p ~ 1e-14). A feature active in no gene now gets an empty set and is counted as not significant. Baseline dimensions are continuous and have no ties, so their sets stay at 50.
- **GO terms with 5 to 500 genes, with annotations propagated to ancestors.** Very small terms give enrichments driven by one or two genes and very large ones are too generic to interpret; propagation lets a gene annotated to a specific term count toward its parents.
- **Benjamini-Hochberg is applied per feature, over that feature's terms; global BH is a sensitivity analysis.** Per-feature correction follows Gujral et al. 2025, which keeps the comparison with the base article direct; correcting across all features and terms at once is stricter and is reported to show how much the result depends on that choice.
- **Genomic windows are embedded on both strands.** Taking the forward strand and the reverse complement of every window matches the sense orientation of genes on either strand; it roughly doubles the window rows (about 18,000) and the embedding compute on the Spark.
- **Embeddings come from `blocks.28.mlp.l3` of Evo 2 7B.** Block 29 of 32 is near the end without being the last one, which specializes in predicting the next nucleotide; it is also the layer of the official Evo 2 embedding example for the 7B. Extraction runs the full forward pass whatever the layer, at about 0.42 s per 1 kb sequence on the Spark (about 2.6 h for genes and windows).
- **Genes with identical sequences are collapsed to one before GO enrichment.** In the 3,583-gene table, 49 genes fall in 11 groups of identical copies, all insertion elements (insH alone has 10); identical sequences get identical embeddings, so every copy lands in the same top-N set and inflates the hypergeometric test, which assumes independent genes. The first copy in table order is kept with the union of the copies' GO terms, leaving 3,545 genes. The SAE still trains on all windows and encodes every gene.
